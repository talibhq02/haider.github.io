Mood Music Recommender

Python

Reads how you're feeling, runs it through a BERT sentiment model, maps the star rating to a mood (1–2★ sad, 3★ nostalgic, 4★ happy, 5★ energetic), and opens your pick in YouTube Music. Type a feeling below — this uses a lightweight keyword approximation of that same star mapping since a 600MB BERT model can't run in a browser tab.

GUI Calculator

Python · Tkinter

Same logic as the source: types into a single field, splits on the first matching operator (+, then −, then ×, then ÷), and converts both halves to numbers. That means no chained expressions — try "5*3-2" and watch it break exactly like the original does. Division by zero is handled gracefully; anything else invalid shows "Error: Invalid input."
